# 💸 План семейного бюджета — веб-обёртка

Удобная и красивая веб-обёртка (на [Streamlit](https://streamlit.io)) для файла Excel
`план_семейного_бюджета.xlsx`. Позволяет смотреть бюджет, редактировать план,
строить графики и сохранять изменения обратно в Excel.

## Возможности

- **📊 Дашборд** — ключевые метрики (поступления, план/факт отложений), круговая
  диаграмма распределения по назначению, сравнение «план vs факт», график поступлений.
- **📅 План по датам** — редактируемая таблица прямо в браузере, фильтры по месяцу и
  статусу, итоговые суммы. Сохранение в отдельный лист Excel.
- **📈 Сводка** — таблица по месяцам и график доходов/расходов.
- **⚙️ Параметры** — исходный лист «Параметры».
- **🌗 Тема** — корректно выглядит и в светлой, и в тёмной теме.

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
./run.sh
# или
streamlit run app.py --server.address 127.0.0.1 --server.port 8501
```

Откроется в браузере: <http://127.0.0.1:8501>

## Структура файла Excel

Обёртка автоматически находит заголовки в листах:

| Лист             | Содержимое                                            |
| ---------------- | ----------------------------------------------------- |
| `Параметры`      | доходы/расходы и сроки по месяцам                     |
| `План по датам`  | по каждому поступлению: сколько на что отложить       |
| `Сводка`         | помесячная сводка и прогресс по целям                 |

## Как это работает

- Файл `план_семейного_бюджета.xlsx` лежит рядом с `app.py`.
- Даты читаются как настоящие даты и показываются в формате `ДД.ММ.ГГГГ`.
- При сохранении правок создаётся **отдельный лист** `План_по_датам_отредактированный`,
  оригинальные данные не затираются.
